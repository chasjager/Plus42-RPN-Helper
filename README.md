## Overview

**Plus42-RPN-Helper** is a tool designed to assist with writing code for Thomas Okken's Plus42 simulator.  Won't wear out your keyboard - no more Ctrl-C and Ctrl-V.
## Current Status

This project is under active development. While the core functionality works, many features are still being implemented and refined.

### What Works
- Basic text editor 
- Copy from Plus42.   Click to transfer an open program in Plus42 into the editor. This will replace the current code in the editor but the code will be saved automatically if you forget to save.
- Paste to Plus42.  Click to transfer code from Plus42 to the editor when Plus42 is in programming mode.
- Toggle Plus42 programming mode. Click to swap Plus42's   program/run state.
- Add common RPN expressions to the editor from clickable listboxes.
